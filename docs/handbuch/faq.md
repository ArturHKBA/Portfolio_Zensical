# ❓ Häufig gestellte Fragen (FAQ)

Du steckst fest? Keine Sorge! Hier sammeln wir die Antworten auf die am häufigsten gestellten Fragen aus der Community.

---

### 🤖 Allgemeines

#### Unterstützt dieses System einen Dark Mode?

**Ja!** Das Design passt sich automatisch den Einstellungen deines Betriebssystems an. Du kannst den Modus aber auch jederzeit manuell über das Sonnen-/Mond-Symbol oben im Header umschalten.

#### Wie kann ich Fehler in der Dokumentation melden?

Wenn dir ein Tippfehler auffällt, kannst du ganz unten auf der betroffenen Seite auf das 👎 (Daumen runter) Symbol klicken. Dort findest du einen direkten Link, um ein vorausgefülltes Ticket bei GitHub zu erstellen.

---

### 🛠️ Fehlerbehebung

#### Fehler: „Command not found“ beim Starten

Dieser Fehler tritt auf, wenn die benötigten Tools nicht global in deinem System registriert sind.

- **Lösung:** Stelle sicher, dass du den Installationsschritt im **[Handbuch](index.md)** exakt befolgt und dein Terminal nach der Installation einmal neu gestartet hast.

---

::: tip 💡 Deine Frage war nicht dabei?
Falls du hier keine Antwort findest, besuche unser externes **[Community Forum](https://deinprojekt.de)** oder wende dich direkt im Slack-Kanal an das Core-Team.
:::
