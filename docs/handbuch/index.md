### ⚡ Quick-Start (Der 5-Minuten-Plan)

Um keine Zeit zu verlieren, folge einfach diesen drei Schritten:

```bash
# 1. Repository klonen
git clone https://github.com

# 2. Abhängigkeiten installieren
npm install

# 3. Entwicklungs-Server starten
npm run dev
```

::: warning ⚠️ Wichtiger Hinweis für Windows-Nutzer
Solltest du beim Installieren auf Berechtigungsprobleme stoßen, lies bitte zuerst den Abschnitt in unserem **[Troubleshooting-Guide](faq.md#fehlerbehebung)**.
:::
